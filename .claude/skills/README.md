# Skills

Two skills, nothing else:

| Folder | What it does |
|---|---|
| `shop-landing/` | The pipeline (this project), with `templates/` for the PRD, TRD, design brief, implementation plan and motion rules. **The templates folder is required**: the planner stops without it. |
| `impeccable/` | The design skill. Decides visual direction, guides motion, and judges the builder's screenshot review. Copy it here from its source repo (the folder that contains SKILL.md). |

Delete any other design skills from this folder (UI UX Pro Max, Emil Kowalski's skill, taste).
The agents are told to ignore them, but leaving them here invites them back in.

The project's own pieces do the rest: the design brief guardrails, `motion-rules.md`,
`templates/site-starter/`, and the screenshot review.

If motion ever starts feeling generic, Emil Kowalski's skill is the first one worth adding
back. Update `shop-planner.md`, `shop-builder.md` and rule 11 in `CLAUDE.md` to give it a role.
